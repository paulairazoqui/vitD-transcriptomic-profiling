# Paper context

This repository accompanies the submitted manuscript:

Gene-level variability, pathway-level convergence: a systems view of vitamin D signaling

The manuscript is based on a LINCS L1000 transcriptomic analysis of vitamin D-related perturbations.

Core manuscript scope:
- 258 perturbational signatures
- 5 human cell lines: A549, HA1E, MCF7, PC3, U2OS
- 7 vitamin D-related compounds
- 24-hour perturbations
- gene-level variability analysis
- Hallmark pathway enrichment
- consensus transcriptional core
- core_score metric
- dose-response analysis
- VDR-axis analysis

The manuscript should not be reframed as:
- a machine learning project
- a drug discovery pipeline
- a portfolio-first project
- a new or expanded analysis beyond the manuscript

## Repository framing

The repository may also contain clearly separated materials for:
- robustness and validation work
- exploratory and future vitamin D transcriptomics analyses
- backend/dashboard support
- provenance and reproducibility infrastructure

These broader platform-oriented components do not automatically constitute manuscript evidence, manuscript claims, validated findings, or changes to manuscript scope.

Exploratory, validation, and infrastructure-oriented materials may exist in the repository without altering the manuscript-confirmatory scientific boundary.
