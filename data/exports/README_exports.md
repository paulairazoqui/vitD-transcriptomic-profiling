# 📂 Exports Directory

This directory stores **final export files** generated by the `export_subset` and related management commands in the `backend/lincs` module.

## Purpose
The files in this folder are the **final processed outputs** derived from the LINCS L1000 dataset after applying all project-specific filters and transformations.  
They are **ready for downstream analysis** (e.g., EDA, modeling) and contain no additional preprocessing requirements.

## File Types (Example Outputs)
- **Metadata tables** (e.g., `subset_compounds_meta.csv`, `subset_cell_lines_meta.csv`)
- **Expression matrices** in wide format (gene ID or gene symbol as columns)
- **Long-format expression data** for flexible querying and joins

## Reproducibility
- **Not versioned in Git** — these files are excluded via `.gitignore` to prevent large binary files from inflating the repository.
- All exports can be **fully regenerated** from:
  1. The raw data in `data/raw_data/`
  2. The processing scripts in `backend/lincs/management/commands/`

## Naming Convention
## Naming Convention

```text
subset_<entity>_meta.csv           # Metadata for a specific entity (compounds, cell lines, genes, signatures)
subset_expression_wide_<type>.csv  # Wide-format expression matrix (gene_id / gene_symbol)
subset_expression_long.csv         # Long-format deduplicated expression data
```

## Notes
- Column definitions and data schema are documented in [`docs/database_documentation.md`](../../docs/database_documentation.md).
- This folder should remain **empty** until exports are generated locally.
- Do **not** manually edit files in this directory; always regenerate using the official scripts.
